# `assets/packs/` — character / style packs

Pack convention is documented at `docs/PACK_CONVENTION.md`.

This directory is intentionally empty / minimal for now.  As the
operator authors packs (folders containing `pack.yaml` + slot
files), they'll appear here and the companion app's Packs page
will populate.

For one-off animations not tied to a pack, the existing
`assets/CATALOG.json` (built by `tools/build_catalog.py`) and the
companion's **Library** page continue to handle browsing.
