! MochiScript v2.0 Language Specification (Final)

This document outlines the syntax and structure of the MochiScript language, a line-based scripting format inspired by FANUC robotics programming for creating complex animations.

---
### 1. Core Concept: The Keyframe

The entire language is built around the concept of a **Keyframe**, referenced by `K[id]`. A keyframe is a link between a command in the `[Main]` section and an asset defined in the `[Resources]` section. This applies to ALL asset-based commands (`MEDIA`, `BITMAP`, `SPRITE`, `MATH`).

The `:name` in `K[id:name]` is an optional, human-readable comment and is ignored by the engine.

---
### 2. File Structure

*   `[Header start]` / `[Header end]`: Informational metadata.
*   `[Main start]` / `[Main end]`: The main executable code block.
*   `[Keyframes start]` / `[Keyframes end]`: Reserved for future use.
*   `[Resources start]` / `[Resources end]`: **Required** definitions for all assets used in the script.

---
### 3. Resource Definitions

Every asset, including `.py` files for `MATH` commands, must be declared here.

**Syntax:** `K[id]: 'path/to/asset.ext'`

**Examples:**
`K[1]: 'assets/media/mochi_logo.png'`
`K[2]: 'assets/media/loading.gif'`
`K[3]: 'assets/sprites/face_sprite.json'`
`K[4]: 'assets/bitmaps/wink.json'`
`K[5]: 'assets/math/timer.py'`

---
### 4. Command Reference

#### Asset Commands

All asset commands use a `K[id]` to reference a resource. They can be used in two modes:

1.  **Load Mode**: When first called, the command loads the asset from the resource path into memory, associates it with the `K[id]`, and executes it. This is the default behavior.
2.  **Event Mode**: If a command includes the `EVENT` argument, it sends the event and its arguments to the *already active* animation associated with that `K[id]`, allowing for interaction.

**MEDIA**
`MEDIA K[id] D[duration] SPD[speed]`

**BITMAP**
`BITMAP K[id] D[duration]`

**SPRITE**
`SPRITE K[id] SRC[x,y,w,h] D[duration]`

**MATH**
`MATH K[id] [ARG[value]] ...` or `MATH K[id] EVENT[name] [ARG[value]] ...`
*   `K[id]`: **(Required)** The key referencing a `.py` math animation file.
*   `EVENT[name]`: (Optional) The name of the event to send to the active animation.
*   `...`: A variable number of standard or custom arguments.

#### Control Flow Commands

**WAIT**: `WAIT D[duration]`
**LBL**: `LBL[id:name]` 
**JMP**: `JMP LBL[id]` (Jumps to a label ID)

---
### 5. Standard Argument Dictionary

These are the standardized keys to be used across all relevant commands.

| Argument          | Key     | Example              | Description                                                    |
| :---------------- | :------ | :------------------- | :------------------------------------------------------------- |
| Duration          | `D`     | `D[5.0]`             | Script wait time for this line.                                |
| Event Name        | `EVENT` | `EVENT[start]`       | The name of an event to send to an active keyframe.            |
| Text              | `TXT`   | `TXT['Hello']`       | A string of text.                                              |
| Size              | `SZ`    | `SZ[3]`              | A general size parameter.                                      |
| X-Coordinate      | `X`     | `X[10]`              | Horizontal position.                                           |
| Y-Coordinate      | `Y`     | `Y[40]`              | Vertical position.                                             |
| Color             | `CLR`   | `CLR[255,0,0]`       | Primary color.                                                 |
| Color 2           | `CLR2`  | `CLR2[0,0,255]`      | Secondary color.                                               |
| Foreground        | `FG`    | `FG[0,255,0]`        | Foreground color.                                              |
| Background        | `BG`    | `BG[0,0,0]`          | Background color.                                              |
| Radius            | `RAD`   | `RAD[12]`            | A radius value.                                                |
| Clear Screen      | `CLEAR` | `CLEAR[1]`           | Boolean-like flag (`1`=true, `0`=false).                       |
| Internal Duration | `DUR`   | `DUR[0.5]`           | An internal duration for an animation's own logic.             |
| Duration (Mins)   | `DUR_M` | `DUR_M[1]`           | A duration specified in minutes.                               |
| Config Path       | `CFG`   | `CFG['path.mscript']` | Path to a configuration file.                                  |
| Source Rect       | `SRC`   | `SRC[0,0,64,64]`     | Source rectangle for sprites.                                  |
| Speed             | `SPD`   | `SPD[1.5]`           | Playback speed multiplier.                                     |
