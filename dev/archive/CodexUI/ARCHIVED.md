# CodexUI archive

CodexUI was the isolated presentation prototype used to establish Anima
Studio's production visual system. Its accepted theme, compact header,
centered workspace navigation, dock/float/canvas panel model, floating ribbon,
status bar, walkthrough, and UI Kit specimens were migrated into `app/` on
2026-07-19.

This directory is retained as design history only. New UI work belongs in the
production `app/Sources/AnimaStudioUI/` components and must receive a matching
UI Dev specimen when it introduces a reusable asset. The renderer experiments
remain separately owned by `dev/Codex Bench/` until their production
integration is explicitly started.
